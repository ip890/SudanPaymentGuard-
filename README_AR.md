# Sudan Payment Guard — الإصدار الأولي 1.0

تطبيق Android مخصص حالياً لصور إشعارات التحويل الخاصة ببنك الخرطوم، بواجهة عربية/إنجليزية، ويحتوي على:

- التقاط صورة بالكاميرا أو اختيار صورة من المعرض.
- OCR محلي باستخدام Tesseract بلغتي العربية والإنجليزية (ملفات التدريب مضمّنة داخل التطبيق).
- محاولة استخراج رقم العملية، أسماء الأطراف، الحسابات، المبلغ، التاريخ والوقت.
- فحوص أولية لجودة الصورة واكتمال البيانات، مع نتيجة مراجعة محافظة.
- حفظ محلي باستخدام Room، والبحث في العمليات، وتصدير تقرير PDF قابل للمشاركة.
- فصل محلل بنك الخرطوم عن بقية التطبيق لتسهيل إضافة محولات بنوك لاحقاً.

## مهم جداً: حدود كشف التزوير

هذا الإصدار لا يستطيع إثبات أن التحويل وصل فعلاً إلى الحساب. OCR وقياسات الصورة وفحص التصميم يمكنها استخراج البيانات وإظهار مؤشرات تستدعي المراجعة فقط. لا توجد حالياً وصلة رسمية ببنك الخرطوم أو API للتحقق من المعاملة. لذلك لا يعرض التطبيق حكماً نهائياً بأن الإشعار أصلي أو مزور؛ يجب التحقق من رصيد حساب المستلم أو قناة البنك الرسمية قبل تسليم أي سلعة أو خدمة.

## البناء في Android Studio

1. افتح مجلد `SudanPaymentGuard` في Android Studio حديث.
2. استخدم JDK 17.
3. اسمح لـ Gradle بتنزيل الاعتماديات من Google Maven وMaven Central.
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ملف APK التجريبي سيظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

الحد الأدنى Android 10 (API 29). تم تضمين `ara.traineddata` و`eng.traineddata` لاستخدام OCR دون اتصال بعد التثبيت.

## ملاحظات النسخة الحالية

- أسماء الأطراف واستخراج رقم العملية قد تحتاج تحسيناً بحسب اختلاف نسخة إشعار بنك الخرطوم وجودة الصورة؛ يجب مراجعة الحقول المستخرجة قبل اعتمادها.
- سجل العمليات محفوظ محلياً على الهاتف. لا توجد مزامنة سحابية.
- تقرير PDF يستخدم إخراج Android النصي مع اتجاه RTL للعربية.
- لا يوجد توقيع رقمي أو اتصال بنكي أو تحقق مباشر من رصيد الحساب.
- لم يُنتج APK داخل بيئة الإنشاء الحالية لعدم توفر Android SDK وGradle مثبتين فيها؛ المشروع المصدر جاهز للفتح والبناء في Android Studio، ويجب تنفيذ بناء فعلي واختبار على هاتف قبل التوزيع.

## البنية

- `data/`: قاعدة البيانات والكيانات.
- `ocr/`: قراءة النصوص وتحليل حقول إشعار التحويل.
- `security/`: فحوص مؤشرات المخاطر.
- `util/`: إنشاء PDF.
- `MainActivity.kt`: واجهة التصوير والبحث وعرض النتائج.
